## Reflection Questions
### What is the purpose of a color map?
To map an image onto an object so that it displays the texture
### What does a normal map simulate?
A normal map simulates a more complicated geometry
### How does a roughness map affect lighting?
A roughness map makes lighting more realistic by causing certain areas to be shinier or rougher
### Which texture improved realism the most and why?
The wood floor definitely improved realism the most. While walls and furniture might realistically be all one color, the floor looked unrealistic until the wood panel texture was added.
### What advantages do texture maps have over adding more geometry?
Using texture maps is usually better than more geometry because you can simulate realism without adding more vertices that require computation. It is also often much easier to use a texture map than to recreate the same things with complex geometries.
